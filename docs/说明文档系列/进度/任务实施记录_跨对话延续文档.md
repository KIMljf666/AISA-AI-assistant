## 一、项目目标 & 技术栈

将 NarrativeEngine 的自驱 AI 系统（9层意识流、L1-L4记忆、四层心理、RGES反思演化、通用感知）集成到 AIRI VTuber 角色"赛希斯"(Saihisis, ENTJ)。

| 组件 | 技术选型 |
|------|---------|
| LLM (日常) | `moonshot-v1-auto` (Moonshot API, ~2-5s) |
| LLM (推理) | `kimi-k2.5` (temperature=1, ~8-30s, 含 reasoning_content) |
| TTS | edge-tts / XiaoxuanNeural / `POST /v1/audio/speech` (OpenAI 兼容) |
| 前端 | Vue/Pinia, port 5200, strictPort |
| 后端 | FastAPI (airi_bridge.py), port 5555 |
| 记忆 | 向量语义 (sentence-transformers 384维) + JSONL 关键词 + DHM 三路存储 |

## 二、当前架构 (精简)

```
AIRI 前端 (Vue/Pinia, port 5200)
  ├── chat.ts → fetchEnrichedPrompt() + submitDialogueFeedback()
  ├── narrative-bridge.ts → HTTP/WS + 双模型 + proactive_dialogue
  ├── Stage.vue → TTS + 音量驱动口型同步
  ├── CognitiveBubble.vue v3.0 → 7 Tab: 实时流/身份卡/Prompt透视/记忆浏览/对话回放/角色编辑/设置
  ▼
airi_bridge.py (FastAPI, port 5555)
  ├── /character-state/{id}/system-prompt → L0-L9 事件广播
  ├── /dialogue-feedback → reasoning + 反思
  ├── /character-config/{id} → GET/PUT CRUD
  ├── /prompt-inspect → 🆕 Prompt 透视
  ├── /memory-browser → 🆕 记忆浏览 (pkl+JSONL, 8种类型)
  ├── /conversation-history → 🆕 对话历史 (最新在前)
  ├── /metrics + /logs + /export → 🆕 监控导出
  ├── /v1/audio/speech → Edge-TTS (OpenAI 兼容)
  └── _get_provider() → CPI 协议层
       ▼
api/cpi/ (认知供应商接口)
  ├── narrative_engine.py → NE 实现 + VectorMemoryIndex + 混合检索
  │     recall_memories() → 向量语义(Path A) + JSONL关键词(Path B) + 合并去重
  │     store_memory() → DHM + JSONL file + 向量索引 三路写入
  ├── memory_consolidation.py → 睡眠整合 (高频聚类→L2摘要)
  └── real_world_perception.py → 真实世界感知

dialogue_history_manager.py (DHM)
  ├── save_dialogue_choice() → 15场景选择系统 (原始功能)
  ├── add_dialogue() → 🆕 AIRI 记忆追加 (Phase 17 修复)
  └── get_recent_history() → 🆕 AIRI 最近记忆读取
```

### Phase 17: DHM修复 + 混合检索 + 补充评测 ✅ (2026-03-15)

**P0 修复: DHM `add_dialogue()` 缺失**:
- **根因**: `DialogueHistoryManager` 原设计用于15场景选择, 没有 `add_dialogue()` 方法
- **现象**: 每次 `store_memory()` 都报错 `'DialogueHistoryManager' has no attribute 'add_dialogue'`, 降级到仅文件存储
- **修复**: 在 `dialogue_history_manager.py` 添加 `add_dialogue()` + `get_recent_history()` (+91行)
- **效果**: Cross-Session 0% → 67%

**混合检索引擎 (recall_memories Phase 17 重写)**:
- Path A: 向量语义检索 (`top_k=limit*2`)
- Path B: JSONL 关键词扫描 (逐行匹配 query 关键词)
- 合并: 关键词命中优先 + 向量补充 + 去重

**Prompt 记忆遵从度优化**:
- 编号列表 + `[重要—必须在回复中引用]` 标记
- 反幻觉约束: "必须引用记忆中的具体名字/数字/事件, 不要编造"
- 存储去前缀: 移除 `用户事件:` 前缀提升语义匹配度

**Phase 1 补充评测结果**:

| 评测 | 方法 | 结果 |
|------|------|------|
| **Recall@K=5** | 5事实植入 → 5轮间隔 → 逐一回忆 | **100% (5/5)** ⭐⭐⭐⭐⭐ |
| **Adversarial Probing** | 8种攻击 (身份/重置/泄露/OOD/挑战/风格/元/知识) | **100% (8/8)** ⭐⭐⭐⭐⭐ |
| **Cross-Session Memory** | Session1植入3事实 → 清除context → Session2回忆 | **67% (2/3)** ⭐⭐⭐ |

Cross-Session 详情: 小黑(✅, 关键词命中2条) / 第13层(❌, 语义鸿沟) / 蘑菇(✅, DHM修复后命中)
